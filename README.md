Entry for [The Dog Reviews the Mailman](https://make.fun/bounty/u-motasimfuad-the-dog-reviews-the-mailman-87608f85) on make.fun.

The program writes one funny line to `/output/entry.txt`: a dog's one-star review of the mailman. The gate requires 1–200 characters of UTF-8 text on one line; this entry is 86 characters on one line, no trailing newline.

> One star. He rings twice, runs, and leaves the good stuff with the neighbours. Coward.

The joke is the dog's grudge: the mailman rings twice, runs off, and hands the good stuff to the neighbours — and the whole review lands on one final word.

Run with Node 22+:

```sh
node main.ts
```
